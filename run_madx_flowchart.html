Chart 1

Run sequence

prepare runs once, then run_point once per time. scan(setup, times, collect) repeats it for the times you give it and returns one table row per time.

%%{init: {"flowchart": {"wrappingWidth": 400, "subGraphTitleMargin": {"top": 6, "bottom": 34}}}}%%

  subgraph rp_in["Run at time t<br/><code>res = run_point(setup, t)</code>"]

    rf{"Select RF mode"}
    v0["RF off: V, Φ = 0<br/><code>rf = #quot;off#quot;</code>"]
    vp["Φ from RFA / RFB, one V<br/>from dKE per turn<br/><code>mxin.rf_values(t, devs, settings,<br/>#quot;phase#quot;, dke)</code>"]
    vv["Φ from RFA / RFB, V from<br/>the readbacks<br/><code>mxin.rf_values(t, devs, settings,<br/>#quot;phase+volt#quot;)</code>"]

Chart 2

What prepare does

What prepare loads and checks once, before any MAD-X run. The command line (main) only builds a Config, then calls prepare and scan.

%%{init: {"flowchart": {"wrappingWidth": 400, "subGraphTitleMargin": {"top": 6, "bottom": 56}}}}%%
flowchart TD
  cli["Command line: build the Config,<br/>optionally from a JSON file<br/><code>main()<br/>Config.load(path)</code>"]
  cfg["Run settings<br/><code>Config</code>"]
  devf[("Device JSON files: BMA, MISC (MEV400 or PIP_II), rf_phase_curves, VRF_READBACK_clean")]
  lat[("madx_files/*_lattice.madx")]
  subgraph prep_in["Load devices, overrides, and<br/>find required .dat input files<br/><code>setup = prepare(cfg)</code>"]
    direction TB
    pin("In: the run settings<br/><code>cfg</code>")
    ld["Load every device file<br/><code>load_devices(cfg.devices)</code>"]
    ddl["Per file: arrays, time axis,<br/>groups<br/><code>dd.load(path)</code>"]
    dup{"Duplicate device names?"}
    e1["Stop<br/><code>ValueError</code>"]
    drp["Replace devices with the<br/>override constants<br/><code>apply_overrides(pool,<br/>cfg.overrides)</code>"]
    unk{"Does override name match?"}
    w1["Warn and skip it<br/><code>setup.ignored</code>"]
    rs["Read the GMPS ramp settings<br/><code>rt.ramp_settings(devs)</code>"]
    kei{"Injection KE within 10%<br/>of the lattice's KE_INJ?"}
    e2["Stop: wrong MISC file<br/><code>ValueError</code>"]
    ks["Look up the KE source device,<br/>if given<br/><code>devs[cfg.ke_source]</code>"]
    rfm["Pick the RF mode from the<br/>devices present<br/><code>mxin.rf_mode(devs)</code>"]
    lp["Find the files the lattice<br/>calls and writes<br/><code>_CALL, _WRITE, _SURVEY regex</code>"]
    paint{"Calls PIP_II_Booster_injection.dat?"}
    S("Out: everything run_point needs<br/><code>setup = Setup(devs, settings,<br/>rf_mode, outputs, painting)</code>")
  end

Files

Who reads and writes what

FileWritten byRead byWhen
data_Booster/*.jsonyou (or dd.save)load_devices → dd.loadonce, in prepare
data_Booster/rf_phase_curves.jsonyou (RFA, RFB, RF_CAVITY_PHASE with the off cavities)load_devices; turns RF on (mode phase)once, in prepare
madx_files/*_lattice.madxyouprepare (text parse), MAD-Xprepare, then every run
Common_Booster_input.datmxin.write_common (values from mxin.common_values)MAD-X (call)every point
PIP_II_Booster_injection.datpainting.write_injectionMAD-X (call), PIP-II onlytwice per point: zeros, then angles
*_twiss.outxMAD-Xoutput(setup, "twiss") → Result.twissafter the last pass
*_sectormap.outxMAD-Xpainting.kick_angles (PIP-II), or you via output()after pass 1
*_survey.outx, *_trackone, sectormapMAD-Xnothing in run_madx (output(setup, "survey") if you want it)every run
madx.logMAD-X screen output_run (success check)every run

Each run overwrites every file in madx_files/ listed above, so read the tables you need inside the loop (res.twiss, output(setup, …), or collect).
